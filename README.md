
# Telecom OSS/BSS Server Health Monitoring

## Project Description
A Linux Bash scripting project designed
to monitor the health of a Linux server.

## Technologies
- Ubuntu Linux
- Windows WSL 2
- Bash scripting
- Linux system commands
- Cron scheduling

## Monitoring Features
1. Server information
2. CPU load monitoring
3. RAM usage monitoring
4. Disk space monitoring
5. Process monitoring
6. Network information
7. System uptime
8. Automatic alerts
9. Log generation
10. Health reports

## Alert Thresholds
- CPU load per core: 80%
- RAM usage: 80%
- Disk usage: 80%

## Execution
chmod +x scripts/server_monitor.sh

./scripts/server_monitor.sh

## Reports
logs/monitoring.log
reports/health_report.txt

## Environment
Ubuntu Linux running on WSL 2.

## Project Type
Linux System Administration Training
